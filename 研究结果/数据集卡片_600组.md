## 2. 生成配置（可完整复现）

```
--res 64 --length 1.0 --T_init 1.0
--dT_min 0.2 --dT_max 1.9              # eps = dT/T0，破缺轴
--Ra_min 1e2 --Ra_max 1e6              # log-uniform
--Ma_expo 0.16666666666666666          # Ma = 8.27e-4*(Ra/1e4)^(1/6)
--numT_left 1~4  --numT_right 1~4  --numT_top 0~2  --numT_bot 0~2
--fr_mode derived                      # Fr = sqrt(dT/T_init)
--buoyancy shifted                     # Pr*Ra*(T-T_init)/dT，Ra_eff = Ra
--stopping steady --newton_seed w0 --newton_mode scale_aware
--seed0 20261016  (seed_bc = seed0 + 10007*idx)
```

本次为避免上游两处已知陷阱，对生成器做了 3 处最小改动（原文件备份为
`genData_stochastic_fourierBC.py.bak_fr`）：

1. `solve_comp` 的 `Fr` 从写死的 1.095 改为可传入，并新增 `--fr_mode {derived,literal}`
   （默认 `derived`，与上游 `genData_3d.py` 完全一致）。
   **上游 `genData_3d.py` 第 575-586 行原文承认**：`Fr^2 = beta*dT = dT/T_init IDENTICALLY,
   so Fr is NOT a free parameter`，写死的 1.095 只在 dT=1.2 时正确。
2. 新增 `--dT_min/--dT_max`，在 Ra 抽样**之后**从同一条 rng 流抽 dT（不设则与上游逐位一致）。
3. meta.json 记录 `fr_mode` / `fr_used`。

## 3. 收敛质量（唯一需要注意的地方）

| 成员 | achieved_rel 中位 | P90 | max |
|---|---|---|---|
| Boussinesq | 2.5e-07 | 7.6e-07 | 9.9e-07 |
| 可压缩 | 3.8e-06 | 1.1e-04 | **7.0e-04** |

- 600 组里 439 组的可压缩成员由 `steady_zero_it_verified` 守卫接受（末步相对变化 < 1e-3）。
- **最差 7.0e-04 相对于最小修正信号 0.043 是 1.6%**，相对中位信号 0.148 是 0.5%。可用。
- 但两个成员**收敛不同步**：低保真收敛到 ~2.5e-7，高保真只到 ~4e-6（中位）。
  即 Y 的噪声大于 X。分析阶段建议按 `march.comp.achieved_rel_change` 加权，
  或在 P1 拟合时剔除 achieved_rel > 1e-4 的那 60 组（~10%）做稳健性对照。

## 4. 用这批数据已经能给出的结果

**P1 标度律（已成立）**：修正项幅度 |Y−X|/|Y| 对 ε 单调、近似线性，
且**跨 4 个数量级的 Ra 几乎完全重合**（见 `dataset_v4_overview.png` A 图）：

| Ra 区间 | ε≈0.4 | ε≈0.8 | ε≈1.2 | ε≈1.6 |
|---|---|---|---|---|
| 1e2–1e3 | 0.043 | 0.107 | 0.167 | 0.245 |
| 1e3–1e4 | 0.050 | 0.111 | 0.192 | 0.279 |
| 1e4–1e5 | 0.057 | 0.095 | 0.183 | 0.245 |
| 1e5–1e6 | 0.064 | 0.100 | 0.171 | 0.239 |

拟合：`||Y-X||/||Y|| ≈ 0.168·eps − 0.022`（ux 通道）。
**含义**：低保真模型对 ε 完全盲（Boussinesq 弱形式里没有 T0/dT），
而离开 ε=1.2 这条公开数据集所在的切片时，误差以约 1 倍的斜率线性增长 —— 没有任何
"只吃 Boussinesq 输入"的网络能预测它。

## 6. 已知限制（写论文时要主动交代）

1. **2D only**。3D 实测单组 >30 min / 2.58 GB（本机 7 GB WSL 只能并行 2 个），
   全量不可行；且 24³ 网格的可信 Ra 上限只有 1e5。计划只做 12~20 组迁移验证。
2. **Ma 在本区间无效应**。固定 Ra/T0/dT 把 Ma 变 24 倍，修正项一位有效数字不变（O(Ma²)）。
   所以破缺群实际是**一维**（ε），不是二维。
3. **ε 上限受 EOS 限制**（Tc = T0 − dT/2 > 0），故 ε < 2。想覆盖更强非 Boussinesq 区需要改
   无量纲化基准，不是简单调参数。
4. 上游"低保真用 Pr·Ra·T、Ra_eff = 1.2·Ra"的缺陷，本批已用 `--buoyancy shifted` 规避，
   因此**与公开数据集在 ε=1.2 处有 0.08% 的 Ra_eff 差**（1.2/1.095² = 1.000813），
   做联合训练时需要知道这一点。
