## 0 一句话

可压缩自然对流里，**Boussinesq 低保真解与可压缩真解之差由单参数 `ε = ΔT/T₀` 决定**：
`‖Y−X‖/‖Y‖ ≈ A·ε`（A = 0.147 / 0.193 / 0.010 / 0.148，四个通道），跨 5 个数量级成立、ε→0 时归零，
并且**在别人公开的 4000 组数据上被独立复现**（u_x 0.1797 vs 本机 0.1839）。
由此得到一条与模型无关的设计规则：把网络拆成 `D = ε·P(X)`，让网络只学 `P`（**ε 完全不进网络**），
它让「只在单个 ε 上仿真过的数据集」可以直接复用到任意 ε。

## 2 标度律

`R = ‖Y−X‖/‖Y‖`，Y = 可压缩、X = Boussinesq。样本 = 600 组随机壁面 + 27 组 ε→0 独立核验点（ε = 0.02/0.05/0.10）。

（主表见 §6 末尾的自动生成表格）主结果：

| 通道 | 幂律 `R = A·ε^p` | A | R² | ε→0 截距（ε≤0.5 段） |
|---|---|---|---|---|
| u_x | p = **1.023 ± 0.018** | 0.147 | 0.84 | +0.0003 ± 0.0047 |
| u_y | p = **0.995 ± 0.019** | 0.193 | 0.82 | +0.0030 ± 0.0062 |
| θ | p = 1.021 ± 0.077 | 0.010 | 0.22 | −0.0003 ± 0.0012 |
| p | p = **1.009 ± 0.015** | 0.148 | 0.87 | +0.0016 ± 0.0030 |

1. **指数与 1 相容**（u_x/u_y/p 误差棒 2%）：修正量线性于 ε 且在 ε→0 时归零。
   之前汇报的「截距 −0.0212 ± 0.0069（3.1σ）」是**拟合窗口伪影**，加上 ε≤0.1 的核验点后消失。
2. **Ra 的次要趋势是真实且可复现的**。把律写成两参数 `R = A·ε^p·Ra^q`：

| 通道 | 单位方腔（600 组） p / q / R² | 宽高比 2:1（104 组） p / q / R² |
|---|---|---|
| u_x | 1.081 / **+0.003 ± 0.006** / 0.74 | 1.071 / −0.143 ± 0.019 / 0.71 |
| u_y | 1.016 / **−0.083 ± 0.005** / 0.77 | 1.146 / **−0.077 ± 0.019** / 0.69 |
| θ | 1.120 / **+0.514 ± 0.015** / 0.72 | 0.989 / **+0.447 ± 0.045** / 0.55 |
| p | 1.127 / −0.029 ± 0.005 / 0.83 | 1.057 / −0.154 ± 0.017 / 0.74 |

   **u_y 与 θ 的 Ra 指数在两种几何里一致**（−0.083 vs −0.077；+0.514 vs +0.447），
   而 **ε 的指数 p ≈ 1 在所有情况下都成立**。→ **ε-标度是几何无关的，系数 A（和 u_x/p 的 q）是几何相关的。**
3. **律与边界条件族几乎无关**：600 组里出现 134 个不同的 (n_L,n_R,n_T,n_B) 族；
   给每个族一个自由截距（133 个哑变量），u_x 的 R² 只从 0.613 → 0.719（校正自由度后 +3.5%）。
4. **θ 通道多一个参数**：散度由基流的对流强度 `χ = ‖u‖‖∇θ‖/‖θ‖` 解释 ——
   `R_θ = ε(−0.0037 + 0.226·χ)`，R² 从 0.185 → **0.778**（Spearman 0.902），常数项≈0 ⟹ 基本就是 `ε·χ`。
   u_x/u_y/p 加 χ 没有改善。

## 3 理论：为什么是 `D = ε·P(X)`（推导 + 数值验证）

方程、ε-展开、O(ε) 源项见 `论文/理论推导_eps展开.md`。要点：

- 密度 `ρ = 1/(1+εθ) = 1 − εθ + O(ε²)`，浮力 `ρg/ε = g/ε − θg + εθ²g + …`
  ⟹ O(1) 系统逐项等于 Boussinesq 方程（Re⁻¹ = sqrt(Pr/Ra)、浮力系数 1、扩散 1/sqrt(RaPr)）。
- O(ε) 连续性源：**`∇·u₁ = ∇·(θ₀u₀)`**（密度变化 ⟹ 速度不再无散）。
- 线性化算子与 ε 无关 ⟹ `D = εP(X) + ε²Q(X) + …`，`P` 的形状不动。

| 预言 | 实测 |
|---|---|
| ε→0 时 R→0 | 截距 0.01σ 内为 0 |
| R ∝ ε | p = 1.023±0.018 / 0.995±0.019 / 1.009±0.015 |
| 修正场形状与 ε 无关 | cos(D(ε), D(1.2)) = 0.95–1.00（四通道 × 5 个 ε） |
| `∇·u₁ = ∇·(θ₀u₀)` | `div(Y)` vs `ε∇·(θu_X)` 余弦 **+0.994**（ε<0.6）/ +0.965（全体） |
| 展开收敛快 | 逐配置 ε¹ 解释 86% 能量，加 ε² → **99.0%**，加 ε³ → 99.9% |

偏差随 ε 单调增大（余弦 0.994 → 0.901）**正是被截断的 ε² 项**，与渐近展开自洽。

## 4 一个必须修的坑：压力通道的单位/静水斜坡

原 600 组打包时把两个成员的**原始压力**直接相减，但可压缩侧的原始压力带静水斜坡
（幅值 12 倍于动力部分），且两个成员弱形式符号相反。

| | 修正前 | 修正后 | 公开数据集（独立管线） |
|---|---|---|---|
| `|X_p|/|Y_p|`（逐样本中位） | 0.065 | **0.960** | **0.929** |
| `cos(X_p, Y_p)`（逐样本中位） | **−0.105** | **+0.991** | **+0.986** |
| p 通道的律 | R ≈ 1.0（无律） | R = 0.148·ε^1.009，R²=0.87 | — |

修正配方与公开数据集一致：**去均值 → 去掉 y 的线性最小二乘拟合 → Boussinesq 侧反号**。
修完后压力通道并入 u_x/u_y 同一族（A ≈ 0.15）。之前汇报的「p 通道提升 6.22×」是单位错配的假象，**作废**。

## 7 先验形式消融：网络学出来的 ε² 项

## 12 收敛噪声不是律的来源

| 检查 | 结果 |
|---|---|
| 600 组可压缩成员 rel_change | 中位 3.75e-6，p90 1.09e-4，最大 7.04e-4 |
| 剔除 rel_change > 1e-4 的 65 组后重拟合 | u_x 斜率 0.1809 → 0.1813，截距 −0.0212 → −0.0221（**不变**） |
| 最差 10 组收紧容差重跑（steady_tol 1e-6 → 1e-8） | 解**逐位不变**：`|ΔY|/|Y| = 0`、`|ΔR|/R = 0` |

最后一条要解释：可压缩成员的步进终止由「Newton 零迭代」守卫（`steady_zero_guard`）决定，
不是 `steady_tol`，所以放宽容差不改变轨迹。⟹ 残留的 rel_change 是**解本身的定点残差**，
不是「没收敛」。加上剔除高噪样本后斜率不动，可以判定律不是噪声撑出来的。

## 14 边界与已知限制（写论文要主动交代）

1. **只有 2D**（3D 成本见 §13）。
2. **Ma 在本区间无效应** ⟹ 破缺群实际是 1 维，不是 2 维。
3. **ε < 2**：状态方程要求冷壁 T_c = T₀ − ΔT/2 > 0。
4. 二参数拟合后 u_x/u_y/θ/p 仍有 26/23/28/17% 的方差没解释（幂律单参数口径是 13–18%），BC 族也补不上（θ 用 χ 或 û 律已解释到 0.90）。
5. A（系数）是几何相关的：单位方腔 0.147/0.193/0.010/0.148，2:1 方腔 0.175/0.175/0.008/0.222。
6. 与公开数据集在 ε=1.2 处的 Ra_eff 差 0.08%（1.2/1.095² = 1.000813），他们的 v2 已修掉。

## 15 水（Pr = 4.38）：同配置只换流体，律完全不动

| test_legacy（经典方腔） | 200 | 0.2984 | 0.3390 | 0.0836 | 0.1983 |

**读法**：指数 p 在这些划分里测不了（各自 ε 固定），但**系数 A 不是普适常数** ——
经典方腔比随机壁面族大 **1.7–1.9 倍**（0.2988 vs 0.1797 train / 0.1567 test_ood）。而这正是「代理模型必须吃 X、不能查表」的理由。
train_legacy 与 test_legacy 中位几乎逐位相同（0.2988 vs 0.2984），是这套数字的自洽检查。

## 17 θ 通道的系数不是自由参数：由流动强度决定

`û = max‖u_X‖`（速度峰值，即 max√(u_x²+u_y²)）是 Boussinesq 输入本身就带的量。六个数据集给出同一条关系：

| 数据 | n | `R_θ/ε = c·û^a` | R² |
|---|---|---|---|
| 本机 600 组（随机壁面，Pr=0.71） | 600 | a = 1.864±0.026，c = 0.544 | 0.90 |
| 公开 train（随机壁面） | 4000 | a = 1.902±0.010，c = 0.602 | 0.91 |
| 公开 test_in_distribution | 200 | a = 1.977±0.041，c = 0.691 | 0.92 |
| 公开 test_ood | 200 | a = 1.931±0.041，c = 0.561 | 0.92 |
| 公开 train_legacy（经典方腔） | 5000 | a = 2.360±0.002，c = 2.063 | **0.995** |
| 公开 test_legacy | 200 | a = 2.368±0.011，c = 2.095 | **0.996** |

两个独立课题组、两个独立生成器、六套数据：随机壁面族的系数都落在 **c = 0.54–0.69**，
经典方腔是 **c = 2.06–2.10**（流动是单个强环流，û 比公开随机壁面中位高 41%、比本机高 56%）。
这同时解释了 §5.1 里 u_x/u_y/p 的残余散度 —— **A 是流动的泛函，而流动就在输入 X 里**。
