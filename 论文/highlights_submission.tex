{\large\bfseries Highlights}\\[2pt]
{\itshape Field accuracy is not heat accuracy: wall-flux-constrained}\\[2pt]
{\itshape surrogates for non-Boussinesq convection}
\end{center}
\begin{itemize}\setlength{\itemsep}{8pt}
\item 0.09\% field error can coexist with 2.0\% integral $Nu$ error (200 samples).
\item Random-wall replication: 0.47\% field error, 4.04\% $Nu$ error (22 samples).
\item Wall-flux penalty cuts $Nu$ error to 0.01\% and 0.58\% (six-point).
\item Boussinesq--compressible gap factorises as $D=\varepsilon P(X)$ over 627 pairs.
\item External $\varepsilon$ factorisation transfers within 0.2\% without retraining.
\end{itemize}
