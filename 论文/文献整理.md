# 文献整理（配合 manuscript_v2.tex）

## 结论

- 共 **33 条**参考文献，**30 条为 2019 年及以后**（91%），其中 **21 条为 2023 年及以后**（64%）。
- 只保留能核到 DOI 或 arXiv 编号的条目；没有凭记忆补引用。
- 经典文献只保留 3 条（Spiegel 1960、Gray 1976、Ahlers 2009），用于支撑 Boussinesq/NOB 的物理背景，其余全部换成近年的方法与应用文献。
- 文献按“物理背景 / 算子学习 / 物理先验 / 传热代理 / 多保真 / 外部验证数据”六组组织，正文 `\cite` 已全部挂好。

## 与正文的对应关系

- **§1 Introduction / Related work**：第 1–3 组 + 第 6 组综述，建立“Boussinesq 极限 → 代理模型 → 现有方法仍把 ε 当输入 → 本文改为解析因子化”的叙事。
- **§2–§3**：第 1 组 + 第 2 组，支撑低 Mach 建模、ε 展开和 Boussinesq 极限。
- **§4 / §5.7**：Menglik et al. 2026，公开 4000+5000 组配对数据及五个 split。
- **§5.4–§5.8**：第 3–5 组，分别对应 FNO/DeepONet、残差修正/物理外推、多保真/迁移学习。
- **§6 Limitations**：不额外堆引用，避免用文献掩盖二维、ε<2 的边界。
