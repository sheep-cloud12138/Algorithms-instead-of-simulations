# 破缺律的渐近推导（附数值验证）

本文件给出「Boussinesq 解与可压缩解之差」为什么是 `D = ε·P(X) + O(ε²)` 的推导，
并逐条给出本机数值验证。所有方程抄自生成器原文
`~/nc_run/DataGeneration/genData_stochastic_fourierBC.py`（`solve_comp` 1143-1211 行、`solve_bq` 1213-1274 行）。

## 1 两个成员的确切方程

**可压缩成员**（稳态；自由落体无量纲化；`u,e,ρ,p` 四个未知量）

```
∇·(ρu) = 0
∇·(ρ u⊗u) = −∇p + (1/Re)∇·σ(u) + (1/Fr²) ρ g
∇·(ρ E u) = (γ/(Re·Pr)) ∇²e + ∇·(P_work u) + O(Ma²)
γ Ma² p + 1 = ρ e                                     (状态方程)
```
`Re = sqrt(Ra/Pr)`、`Pr = 0.71`、`γ = 1.4`、`g = (0,−1)`、
`Fr² = ΔT/T₀ ≡ ε`（`fr_mode=derived`，生成器原文注释：
*"In this non-dimensionalisation Fr² = beta·ΔT = ΔT/T_init IDENTICALLY, so Fr is NOT a free parameter"*）、
初值 `ρ = 1/T₀`。

**Boussinesq 成员**（稳态；同一套自由落体尺度；`shifted` 浮力）

```
∇·u = 0
u·∇u = −∇p + sqrt(Pr/Ra) ∇²u + ((T−T₀)/ΔT) ĝ
u·∇T = (1/sqrt(Ra·Pr)) ∇²T
```
其中 `1/Re = sqrt(Pr/Ra)`、`c_buoy = 1`、`c_cond = 1/sqrt(Ra·Pr)` 三个系数就是
生成器里 `BOUSS_SCALING = freefall` 分支写死的值。

> 关键结构性事实：**Boussinesq 成员的方程里根本没有 T₀、ΔT，只出现 θ=(T−T₀)/ΔT。**
> 这正是配对集上「低保真解对 ε 逐位不变」（最大相对偏差 9.77e-8）的数学原因。

## 2 ε-展开

令 `T = T₀(1 + εθ)`（θ 是 O(1)），由状态方程与初值 `ρ = 1/T`：

```
ρ = 1/(1 + εθ) = 1 − εθ + ε²θ² − …
```

**连续性** `∇·(ρu) = 0`，取 `u = u₀ + εu₁ + …`：

| 阶 | 方程 |
|---|---|
| O(1) | `∇·u₀ = 0` —— 与 Boussinesq 连续性完全相同 |
| O(ε) | `∇·u₁ = ∇·(θ₀u₀)` —— **密度变化使得可压缩速度不再无散** |

**动量**：浮力项 `(1/Fr²)ρg = ρg/ε`，前两项是
`g/ε`（静水背景，被后处理去掉）与 `−θ₀g`（即 O(1) 浮力，和 Boussinesq 的浮力项逐项相同）。
O(ε) 的剩余源项来自**惯性项里的密度变化**：

```
∇·(ρ u⊗u)  →  O(ε):  ∇·(u₁⊗u₀ + u₀⊗u₁ − θ₀ u₀⊗u₀)
```

**能量方程**：O(1) 化为 θ 的对流-扩散（即 Boussinesq 的温度方程）。
这一条不逐项展开，而是由第 3 节的 ε→0 数值极限整体验证。

## 3 结论与可检验预言

把上面写成算子形式：Boussinesq 解 `X` 是 O(1) 解，修正场 `D = Y − X` 满足

```
L[D] = ε·S₁[X] + ε²·S₂[X] + …          L = 线性化 Boussinesq 算子（与 ε 无关）
⟹  D = ε·P(X) + ε²·Q(X) + …            P = −L⁻¹S₁,  Q = −L⁻¹S₂
```

四条可检验预言，全部已在本机核对：

| # | 预言 | 实测 | 证据 |
|---|---|---|---|
| 1 | 修正量 `R = |Y−X|/|Y|` 在 ε→0 时归零 | 截距 `+0.0003 ± 0.0047`（ux，0.01σ） | 627 点（600 组 + 27 组 ε=0.02/0.05/0.10 核验） |
| 2 | `R ∝ ε`（指数 1） | p = 1.023±0.018 / 0.995±0.019 / 1.021±0.077 / 1.009±0.015 | 同上，跨 5 个数量级 |
| 3 | 修正场**形状**与 ε 无关（只是幅度变） | cos(D(ε), D(1.2)) = 0.95–1.00（四通道，5 个 ε） | 配对集 20 配置 |
| 4 | O(ε) 连续性修正 = `∇·(θu₀)` | `div(Y)` 与 `ε∇·(θu_X)` 余弦 **+0.994**（ε<0.6）、+0.965（全体）；幅值 2.26e-2 vs 2.10e-2 | 600 组中 200 组，二阶中心差分 |
| 5 | 展开收敛快：2 项吃掉绝大部分 | 逐配置 D(ε) 用 ε¹ 解释 86%，加 ε² 到 **99.0%**，加 ε³ 到 99.9% | 配对集 20×5 |

预言 4 的偏差随 ε 单调增大（ε<0.6 时余弦 0.994、ε>1.4 时 0.901），
**正是被截断的 O(ε²) 项**，而不是模型出错——这与预言 5 自洽。

## 4 适用边界

| 边界 | 依据 |
|---|---|
| `ε < 2` | 状态方程要求 `T > 0`：冷壁 `T_c = T₀ − ΔT/2 > 0` ⟹ `ε = ΔT/T₀ < 2` |
| Ma 项可忽略 | 固定 Ra/T₀/ΔT，把 Ma 变 24 倍，修正项幅度到 5 位有效数字都不变（O(Ma²)） |
| Fr 不是独立轴 | `Fr² ≡ ε`，两者是同一个数 |
| 本推导只用到 `ρ = 1/T` 与浮力项结构 | 不含拟合参数；四个通道的 A 值（0.147/0.193/0.010/0.148）是**由数据测出的**，不是推导出来的 |
