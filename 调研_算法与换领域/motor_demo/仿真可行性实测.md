# 电机绕组切换：纯仿真可行性实测

日期：2026-10-18　机器：i7-14650HX（16C/24T），Python 3.14，numpy 2.4.2，scipy 1.17.1，纯 CPU

## 一句话结论

**能仿真，而且已经跑通。** 2D 非线性静磁 44,800 单元、118 s/工况；但"绕组切换瞬态"不是多算几个静磁场那么简单，需要场-路耦合，成本高一个量级；纯仿真投 IEEE 电机顶刊仍然很难。

## 实测方法与结果

方程 `-div(nu grad A_z) = J + (curl M)_z`，极坐标有限体积，4 极 / 12 槽表贴式永磁，铁芯用 Fröhlich 型饱和 B-H，永磁径向充磁（磁极边缘 5° 平滑过渡）。网格 140×320 = 44,800 单元，56 次非线性迭代。

| 指标 | 实测值 | 判断 |
|---|---|---|
| 气隙平均 \|B\| | 0.594 T | 合理。1D 磁路估算 0.86 T，乘 0.8 磁钢占空比得 0.69 T，再扣槽漏磁，0.59 T 对得上 |
| 气隙峰值 \|B\| | 1.75 T | 槽口附近，合理 |
| 永磁体最大 \|B\| | 1.81 T | 磁极边缘集中，局部偏高但可解释 |
| 铁芯最大 \|B\| | 3.73 T | 槽口尖角的数值奇异，非物理；实际设计要倒圆角或局部加密 |
| 转矩（Maxwell stress） | 54 N·m/m（细网格） | **未网格收敛**：粗网格算 122 N·m/m。只能看量级，不能当结论 |
| 单工况耗时 | 118 s（细）/ 9 s（粗） | 纯 CPU，单核直接稀疏求解 |

### 这个结果可信到什么程度

- 可信：气隙磁密量级、4 极磁通走向、饱和趋势、单工况成本。这三条足以支撑"能不能做"的判断。
- 不可信：转矩绝对值（气隙只有 2~3 个径向单元，Maxwell stress 对网格敏感）、铁芯尖角峰值、铁损。
- 没做：网格无关性、实验对标、磁钢涡流、端部效应、非线性 Newton 收敛（现在定点迭代停在 rel≈1e-4）。

## 绕组切换要仿真什么

| 层级 | 模型 | 单次成本 | 能回答的问题 |
|---|---|---|---|
| L1 稳态地图 | 2D 静磁 + 后处理 | 9~118 s/点 | 每种接法下的转矩、磁链、反电势、效率包络 |
| L2 准静态切换 | 预计算磁链/转矩查表 + 电路方程 | 毫秒级 | 切换时刻、冲击电流、转矩跌落（工业标准做法） |
| L3 场-路耦合瞬态 | 每步解场 + 外电路 + 运动 | 9 s/步（粗网格） | 切换过程中的涡流、磁链突变、电流纹波 |
| L4 3D/多物理 | 3D 电磁 + 热 + 结构 | 小时~天 | 端部、温升、噪声；**不建议**，超出资源 |

关键点：**L2 才是绕组切换研究的主力**，L1 给它提供查表数据；L3 只在少数关键工况做验证。把 L3 当日常工具，算力会立刻不够。

## 算力账

- 一张完整的稳态地图：3 种接法 × 12 个转子位置 × 10 个电流 = 360 点 → 细网格 12 h，粗网格 54 min。
- 一次 20 ms 切换瞬态（dt=20 μs，1000 步）：粗网格 2.5 h/次；细网格 33 h/次。
- ML 训练集 300~500 个工况，每工况 5 个点：粗网格 4~6 h，细网格 50~80 h。
- 结论：**做数据不卡算力，卡的是"高保真标签从哪来"和"拿什么证明标签对"。**

## 发表判断（有检索依据）

- `winding switching` 150 篇，`winding reconfiguration` 51 篇；`+ machine learning` = **0**，`+ optimization` = 4，`+ EV` = 0。
- 0 篇不等于空白，可能是"没人需要"：这个问题的传统解法是"电路模型 + 遗传算法/动态规划"，已经够用。
- IEEE TIE / TPEL / TEC：默认要实验台架。纯仿真投这些刊，审稿人第一句就是 "experimental validation is missing"。
- CMAME / MLST / Neurocomputing / 工程类 ML 刊：纯仿真可以，但 ML 贡献必须立得住，不能只是"又一个电机代理模型"。

## 如果要做，建议的定位

不要做"固定拓扑的电机代理模型"（已经很多）。做**拓扑可变的算子学习**：

- 输入：绕组连接矩阵（串/并/星/角/有效匝数）+ 转子位置 + 电流
- 输出：磁链、转矩、铜损/铁损
- 泛化测试：留出**没见过的接法**做 zero-shot，这是普通代理模型做不到的
- 价值：把"切换序列优化"从"每种接法重跑一遍 FEA"变成"一次前向"

这条路纯仿真能成立，但要先回答一个问题：**切换带来的收益，是否大到值得为它学一个模型？** 最便宜的验证是 L1 地图：3 种接法 × 12 个转子位置，画转矩-速度包络。如果三种接法的包络几乎重合，idea 直接否掉，省几个月。
