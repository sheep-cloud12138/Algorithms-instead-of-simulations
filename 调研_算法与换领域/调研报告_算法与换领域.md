## 0. 一页结论

**结论一：你的内核是对的，但载体选错了。**
"把相似律破缺量本身当学习对象" —— 这个内核不只适用于可压缩自然对流。它是一类通用问题：**任何教科书级相似律在极端参数下失效的地方，都长着同一个缺口**。而那些地方，比 2D 方腔可压缩 NOB 的占位更空、数据更便宜、审稿人更认。

**结论二：换领域不必换出传热。**
留在 IJHMT / Applied Thermal Engineering 的主场，只换物理机制 —— 这是风险最低的换法。你现在要解决的三个真问题（撞车 2606.25259、判别式恒真、审稿人一句"这不就是喂无量纲群吗"）**一个都没解决**，换到超临界传热或相变，它们会自动消失，因为你不再需要一个"低保真求解器"当卖点。

**结论三：最推荐的三个候选，证据强度从高到低。**

| 排序 | 方向 | 为什么 | 最硬的一条证据 |
|---|---|---|---|
| **1** | **超临界 CO2 传热恶化（HTD）** | 传热界最有名的"关联式失效"，工程需求真实，1D 管流数据极便宜 | `"supercritical" + "operator learning"/"FNO"` = **0 篇**；`"heat transfer deterioration"` 本身 **849 篇** |
| **2** | **相变 / Stefan 相似解破缺** | 有精确相似解（Neumann 解）可当低保真底座，与现在的多保真结构同构 | `"Stefan problem" + "machine learning"` = **3 篇**（全是解正/反问题的 PINN，无人学破缺量）；`"phase change"+"similarity solution"+ML` = **0** |
| **3** | **稀薄气体 / 微纳尺度（Knudsen）** | 破缺群干净（Kn 数），领域刚被一篇 2026 Perspective 立规 | `"rarefied gas" + surrogate` = **15 篇**；`"Knudsen number"+"machine learning"` = **6 篇** |

**结论四：算法侧，你现在用的 FNO 骨架是对的，别换。**
PINN 已经死了（16 005 篇，其中 11 221 篇是 2025 年之后 —— 不是红海，是血海）。FNO / DeepONet 是标准件。真正有空位的是**外推 / OOD**（255 + 322 篇）和**PDE 基座模型**（199 篇，142 篇在 2025 之后）。换架构换不来创新分，换问题可以。

**结论五（必须知道的坏消息）：你方案里的 P1 判据，已经有人做过同型工作。**
`2406.03896`（Physical Review E 2024）《Data-driven discovery of self-similarity using neural networks》—— **把幂律单项式结构硬编码进网络、从数据里反解出标度指数**。这正是你 P1 想做的事的通用版本。你的 P1 必须重新定位（见 §6）。

### 2.2 三个可执行的结论

**① 别在 PINN 上花一分钟。** 16 005 篇里 70% 是 2025 年之后发的。这不是竞争激烈，是已经没有信息量了。

**② 你的 FNO 骨架是对的，别换。** 现有证据：在小数据 2D PDE 上做过公平对比，普通多通道 U-Net 打赢了 ViT、PDE-Transformer 和 KAN-UNet（arXiv 2601.08404，你 2026-10-15 的调研已收录）。**架构不是你的变量，问题才是。**

**③ 真正的空位在"外推/可信度"这一层，不在"架构"这一层。**

- 外推 × 神经算子 255 篇、OOD × 代理 322 篇 —— 相对神经算子总量 4 598 篇，只占 5~7%。**"外推"是现在神经算子最大的未解问题，而不是最卷的问题。**
- PDE 基座模型 199 篇、其中 142 篇在 2025 之后 —— 一年内的爆发。这是"赛道刚开"的信号，也是"半年后会卷"的信号。
- Mamba/SSM × PDE 只有 25 篇、扩散 × PDE 代理只有 16 篇 —— 如果你确实想换架构（我不建议），这两个是最空的。

## 3. Part B：怎么筛"换哪个领域"

你原来的不同点只有一句："没人把破缺量当学习对象。"这句话要能成立，需要**同时**满足四个条件。这就是筛子。

### 3.1 四个条件

| # | 条件 | 为什么必须有 | 怎么验证 |
|---|---|---|---|
| **C1** | **存在一个教材级的相似律 / 经验关联式** | 没有公认的"正确",就无所谓"破缺"。这是整篇论文的锚 | 该关联式至少出现在教科书或 100+ 篇文献里 |
| **C2** | **这个相似律在某个无量纲群下会破**，且破缺有工程后果 | 有后果才有论文价值（Nu 偏 30% ≠ 只是好玩） | 该现象有独立命名（NOB / HTD / 尺寸效应…） |
| **C3** | **该领域没人做过"破缺量本身"的数据驱动研究** | 这是你的创新分 | 标题+摘要精确检索，命中数应 < 10 |
| **C4** | **你自己的机器能造出配对数据** | 数据造不出来，一切白搭 | 低保真：秒~分钟级、CPU、2D；高保真：分钟~小时级 |

### 3.2 我用 C1~C3 扫过的领域（全部数字可核）

| 领域 | 相似律（C1） | 破缺群（C2） | ML 饱和总量 | **破缺角度的 ML 命中（C3）** | 判断 |
|---|---|---|---|---|---|
| **超临界 CO2 传热恶化** | Dittus-Boelter / Jackson 关联式 | p/p_cr、T_b/T_pc、q/G、浮升力 | `"supercritical"+"heat transfer"+"NN"`=48 | `"supercritical"+operator learning/FNO`=**0**；`HTD+ML`=**3** | ✅ **最优** |
| **相变 / Stefan** | Neumann 相似解、等温相变 | 有限速率动力学、多相共存、对流、变物性 | `"phase change material"+ML`=1314 | `"Stefan"+ML`=**3**；`相似解+ML`=**0** | ✅ 优 |
| **稀薄气体 / 微纳** | 连续介质+NS+无滑移 | Kn 数 | `"rarefied gas"+ML`=55 | `"rarefied gas"+surrogate`=**15**；`Kn+ML`=**6** | ✅ 优（但有 review 抢定义权） |
| **非傅里叶 / 非局部传热** | Fourier 定律 + 局部平衡 | 微纳尺度、超快激光、双相位滞后 | `"phonon transport"+ML`=184；`BTE+ML`=171 | `"non-Fourier"+ML`=**3** | ⭕ 可选（物理门槛高） |
| **多孔介质非 Darcy** | Darcy 定律 | 孔隙 Re（Forchheimer） | `"Forchheimer"+ML`=255；`"non-Darcy"+NN`=27 | 绝大多数是"纳米流体+拉伸板"式 ANN 回归，**几乎无价值** | ⭕ 可选（噪声多） |
| **混合对流** | 纯自然/纯强制对流 | Ri / Gr/Re² | `"mixed convection"+ML`=301（S2 42） | 有 2021 湍流 Prandtl 数数据驱动模型，逼近 | ⭕ 中等 |
| **变物性自然对流（经典 NOB）** | Boussinesq 相似律 | 变物性 | — | `"variable properties"+"natural convection"+ML`=**0** | ⭕ 但这是你原方向 |
| **湍流标度律** | Kolmogorov 标度 | 间歇性、可压缩、浮力 | `turbulence+scaling/similarity+ML`=139 | 2025 JFM 已有"知识嵌入的近壁建模" | ❌ 偏挤 |
| **断裂尺寸效应** | LEFM 强度尺寸无关 | 准脆性过程区/结构尺寸 | `fracture+ML+surrogate`=363 | `size effect+ML+fracture`=**8**（全是实验回归） | ⭕ 但换领域成本高 |

| **临界热流密度（CHF）** | 各类 CHF 关联式 | 流型转变 | `CHF+ML`=**69** | 已有 physics-informed CHF 框架多篇 | ❌ 已被占 |

### 3.3 筛完的结论

**只有前三行同时满足 C1~C4。** 其中"超临界 CO2 传热恶化"在三个维度上全面领先：

- C1 最强：Dittus-Boelter 是传热学第一课就教的关联式，它"在超临界区失效"是传热界的常识级悲剧。
- C2 最硬：`"heat transfer deterioration"` 有 **849 篇**独立文献，是**有正式名字的工程灾害**（超临界锅炉爆管、sCO2 循环效率塌陷）。
- C3 最空：把 ML 用在 **1D 管流标量预测** 上有 48 篇，但用在 **算子学习/破缺量** 上 **0 篇**。
- C4 最省：1D 管流轴对称稳态求解，比你现在的 2D 方腔**便宜一个数量级**；也根本不需要 3D。

## 4. Part C：五个具体 idea

> 每个 idea 给出：相似律 / 破缺群 / 证据 / 数据成本 / 风险 / 推荐度。
> 所有命中数见 §2.1 与 §3.2，原始响应在 `raw/`。

### Idea 1（首推）：超临界 CO2 传热恶化 —— 学"关联式失效量"

| 项 | 内容 |
|---|---|
| **相似律** | Dittus-Boelter：`Nu = 0.023 Re^0.8 Pr^0.4`（以及 Jackson 的超临界修正式） |
| **破缺群** | 约化压力 `p/p_cr`、壁面-拟临界温差 `(T_w - T_pc)/T_pc`、热流密度 `q`、质量流速 `G`、浮升力参数 `Bu = Gr/Re^2` |
| **低保真底座** | Dittus-Boelter 关联式（**一条公式，零成本**）或常物性 N-S 解 |
| **高保真** | 变物性（含拟临界区剧烈变化的 cp、ρ、λ）可压缩管道流动 |
| **学习对象** | `Δ = Nu_HF - Nu_DB`，即"关联式的失效量" |
| **为什么是新东西** | 现有 48 篇全是"用 ANN 回归 Nu / 预测 HTD 边界"（表格级，无外推评估、无破缺群）。**没人把失效量当有结构的物理对象学，没人做 `p/p_cr` 方向的外推** |
| **数据成本** | 1D 管流，单次求解秒~分钟级；扫 300~600 组在单机上就是几小时 |
| **可迁移判据** | 低 `p/p_cr` 训练 → 高 `p/p_cr`（逼近临界点）测试。**这就是你 P2 的干净版本** |
| **风险** | ① S2 有 1 篇 2023 ATE《ML based prediction of HTD in upward vertical tubes》—— 必须先读透并正面区分（它是表格级预测，你是破缺量结构 + 外推）。② 超临界物性需要准确的 IAPWS/REFPROP 物性表 |
| **推荐度** | ⭐⭐⭐⭐⭐ |

### Idea 2：相变 / Stefan 相似解破缺 —— 学"界面动力学偏差"

| 项 | 内容 |
|---|---|
| **相似律** | Stefan 问题有精确相似解（Neumann 解）：界面位置 `s(t) ∝ √t`，由 Stefan 数唯一决定 |
| **破缺群** | 过冷度 `Ste`、有限速率界面动力学（界面迁移率 / 动力学系数）、Péclet（对流相变）、变物性 |
| **低保真底座** | Neumann 相似解（**解析闭式，零成本**）或焓-多孔法等温相变 |
| **高保真** | 相场法 / 尖锐界面 + 有限速率动力学 |
| **学习对象** | `Δ = s_HF(t) - s_Neumann(t)`，以及界面温度偏差 |
| **为什么是新东西** | `"Stefan problem"+"machine learning"` 只有 3 篇，**全是 PINN 解正/反问题**，无人学破缺量；`"phase change"+"similarity solution"+"machine learning"` = **0** |
| **数据成本** | 1D/2D Stefan 秒~分钟级，**这是所有候选里最便宜的** |
| **额外加分** | `s(t) ∝ √t` 这个标度律给你一个**极干净、可解析验证的判据**：P1（指数是不是 0.5）、P2（低 Ste 训练 → 高 Ste 测试）都能解析地判定对错，而不是靠"拟合 R²" |
| **风险** | PCM + ML 总量 1314 篇，容易被误归到"又一个 PCM 代理"。必须在标题和摘要第一句就锁死"相似解破缺" |
| **推荐度** | ⭐⭐⭐⭐⭐（性价比最高） |

### Idea 3：稀薄气体 / 微纳尺度 —— 学"连续介质假设的失效量"

| 项 | 内容 |
|---|---|
| **相似律** | Navier-Stokes + 无滑移 + Fourier 导热（连续介质相似律） |
| **破缺群** | Knudsen 数 `Kn = λ/L`（可细分速度滑移、温度跳跃、非平衡区） |
| **低保真底座** | NS + 一阶/二阶滑移边界（**解析闭式可用**） |
| **高保真** | DSMC 或 Boltzmann-BGK 求解 |
| **学习对象** | 滑移修正量 / 壁面应力与热流的偏差 |
| **为什么是新东西** | `"rarefied gas"+surrogate`=15、`Kn+ML`=6，且 2026 出了 Perspective 综述在**立规矩**（明确要求外推测试 + 噪声感知指标 + 三级验证） |
| **数据成本** | ❌ **这是它最大的问题**：DSMC 很贵（单次分钟~小时、且是随机噪声标签）。1D/2D 简化算例可行，3D 不可行 |
| **风险** | ① 数据生成贵，会吃掉你的时间预算；② 那篇 2026 Perspective 已经在给这个方向定评估标准，**半年内会出现一批跟进工作** |
| **推荐度** | ⭐⭐⭐ |

### Idea 4：非傅里叶 / 非局部传热 —— 学"Fourier 定律的失效量"

| 项 | 内容 |
|---|---|
| **相似律** | Fourier 定律 `q = -k∇T` + 局部热平衡 |
| **破缺群** | 热松弛时间 / 声子平均自由程比 `τ/t`、`Kn_ph`；双相位滞后（DPL）的两个滞后时间 |
| **低保真底座** | Fourier 抛物型解（含解析解：半无限体 + 阶跃/周期热流） |
| **高保真** | 双曲型热波方程 / 声子 BTE / 双亥姆霍兹非局部理论 |
| **为什么是新东西** | `"non-Fourier"+heat conduction+ML` = **3 篇**（且都是 PINN 解方程，不是学破缺量） |
| **数据成本** | 双相位滞后模型是解析可算的（便宜）；但真 BTE 很贵 |
| **风险** | 物理门槛高 —— 审稿人会问"这些滞后时间的物理来源是什么"，而这本身是争议话题。容易写成"玩具算例" |
| **推荐度** | ⭐⭐ |

## 6. 必须知道的撞车与风险清单

### 6.1 🔴 P1 的新风险：`2406.03896`

**《Data-driven discovery of self-similarity using neural networks》**，Physical Review E，2024（arXiv 2406.03896v3）。

原文摘要关键句：

> "The presence of self-similar solutions in a physical problem signals that the governing law contains a function whose arguments are given by power-law monomials of physical parameters, which are characterized by power-law exponents. **The basic idea is to enforce such particular forms structurally in a neural network in a parametrized way.** ... when the training is successful, we can extract the power exponents that characterize scale-transformation symmetries of the physical problem."

**它做的正是你 P1 想做的事的通用版本**：把幂律结构硬编码进网络、从数据里反解标度指数。

**怎么切割**：它发现的是**存在的相似律**（self-similarity discovery）；你学的是**相似律的破缺**（departure），破缺项**本身不是幂律**，而是对幂律的偏离。这个区别是真的，但你必须**主动写进引言**，不能装看不见。

### 6.4 一条方法论上的提醒

你 v3 证据版里的 §1.2 结论（"参数注入零增益，因为有底座的修正才有效"）**在换到 Idea 1 后可能会失效**：

- 原数据里 `X` 已经完整编码了 Ra（PCA 反推 R² ≥ 0.9999），所以加 Ra 是冗余的。
- 但超临界问题里，**壁温、热流、压力是独立于速度场的边界条件**，不会像 Ra 那样被场本身编码。也就是说，**参数注入在 Idea 1 里可能是真的有用的**。
- 这意味着：你原方案里那条"物理先验零增益"的负面结论，**不能直接搬到新方向当结论用**，必须重测。
